# Show — Seminário

Esta pasta é a versão de apresentação visual do projeto.

O projeto original permanece intacto. O show é independente e usa apenas um arquivo HTML, sem instalação de bibliotecas e sem depender de internet.

## Controles

- Mouse: ativa a "lente" visual.
- Setas esquerda/direita: troca de cena.
- Espaço: próxima cena.
- Esc: volta ao início.

## Atalhos na raiz

- **Abrir Show Seminario.bat** — abre a experiência visual.
- **Abrir Terminal Seminario.bat** — executa o projeto original.

Os números e elementos do show são ilustrativos; não representam resultados oficiais.
